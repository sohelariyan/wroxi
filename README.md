## ✨ Features

- 🔐 **Auth** — Sign up, Login, Forgot Password with Email OTP
- 📝 **Feed** — Post text & photos (280 char limit)
- ❤️ **Like** — Like posts & comments
- 💬 **Comments** — Comment + Reply (nested)
- 👥 **Follow System** — Follow/Unfollow with separate Followers & Following lists
- 💌 **Messaging** — Direct message between users
- 🌙 **Dark / Light Mode** — Toggle anytime
- 📱 **Mobile Responsive** — Works on all screen sizes
- ℹ️ **About** — Accordion info section on login page

npm run build
